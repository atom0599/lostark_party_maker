# ⚡ LOA SMART PARTY MAKER

**로스트아크 공대원 원정대 관리 및 최적 파티 자동 조합 시스템**입니다. 
여러 원정대의 캐릭터 정보를 한눈에 관리하고, 레이드별로 최적의 파티를 자동으로 구성할 수 있습니다.

## 🌟 주요 기능

*   **원정대 자동 등록**: 캐릭터명 검색을 통해 원정대 내 모든 캐릭터의 레벨, 전투력, 직업 정보를 자동으로 불러옵니다.
*   **레이드 세부 설정**: 각 캐릭터별로 참여 가능한 레이드를 지정하고, 딜러/서포터 역할을 유동적으로 변경할 수 있습니다.
*   **최적 파티 자동 조합**: 파티 타입(4인/8인), 서포터 배치, 레벨 조건, 원정대 중복 방지 등 복잡한 조건을 고려해 최적의 조합을 찾아줍니다.
*   **다양한 보기 모드**: 
    *   **카드 보기**: 직관적인 캐릭터 카드 형태로 관리.
    *   **표 요약 보기**: 파티 구성을 표로 정리하여 한눈에 확인.
*   **테마 전환**: 라이트 모드 및 다크 모드를 지원합니다.

## 🛠️ 기술 스택

*   **Framework**: Next.js (App Router)
*   **Styling**: Tailwind CSS
*   **Storage**: localStorage (개별 브라우저 내 데이터 저장)

## 📖 사용 방법

1.  **원정대 등록**: 메인 화면 입력창에 대표 캐릭터명을 입력하여 원정대를 등록하세요.
2.  **캐릭터 설정**: 캐릭터 카드 우측 상단의 `⚙️` 버튼을 눌러 참여할 레이드를 확인 및 설정하고, 필요 시 역할을 딜러/서포터로 전환하세요.
3.  **조합 실행**: `⚡ 최적 파티 자동 조합` 버튼을 누르면 조건에 맞는 파티 결과가 하단에 생성됩니다.
4.  **결과 확인**: 상단의 스위치를 통해 '표 요약'으로 전환하거나, 필터를 사용하여 특정 레이드/원정대별로 결과를 확인하세요.

## 📝 참고 사항
*   이 프로젝트는 브라우저 로컬 환경(`localStorage`)에 데이터가 저장됩니다. 
*   다른 기기나 다른 브라우저에서는 공대 정보가 동기화되지 않으니 필요 시 표 요약 기능이나 스크린샷을 통해 공유해 주세요.
