# LOA SMART PARTY MAKER

로스트아크 공대원 원정대를 함께 관리하고, 레이드별 파티를 자동으로 조합하는 웹 사이트입니다.

## 주요 기능

- **원정대 등록 / 갱신**: 대표 캐릭터명으로 원정대의 1700 이상 캐릭터(레벨 · 전투력 · 직업)를 불러옵니다. 전체 원정대를 한 번에 갱신할 수도 있습니다.
- **캐릭터별 레이드 설정**: 참여할 레이드 난이도, 딜러/서포터 역할, 매칭 제외를 캐릭터마다 지정합니다.
- **최적 파티 자동 조합** (관리자): 직업 · 원정대(부계정 포함) 중복 없이 앞 파티부터 꽉 채우고, 같은 레이드의 파티끼리 전투력을 맞춥니다. 4인 레이드가 8인 레이드보다 위에 표시됩니다.
- **수동 편집** (관리자): 캐릭터를 다른 파티의 캐릭터와 바꾸거나 빈 자리로 옮깁니다.
- **클리어 현황 · 주간 초기화**: 파티별 클리어 체크와 주간 초기화를 할 수 있습니다.
- **레이드 관리**: 레이드 · 난이도 추가와 수정, 배경 이미지 업로드를 할 수 있습니다. 삭제는 관리자만 할 수 있습니다.
- **파티 텍스트 복사**, **변경 기록** (관리자)

## 데이터 공유

원정대 · 파티 · 레이드 목록은 서버(`/api/state`)에 저장되어 모든 접속자가 함께 봅니다. 몇 초마다 동기화하며, 여러 명이 동시에 수정하면 캐릭터 · 필드 단위로 병합합니다.

## 환경 변수

| 이름 | 설명 |
| --- | --- |
| `LOA_API_KEY` | 로스트아크 Open API 키 |
| `ADMIN_PASSWORD` | 관리자 비밀번호 |
| `SUPABASE_URL`, `SUPABASE_SERVICE_ROLE_KEY` | 공유 저장소 (`kv_store` 테이블) |
| `KV_REST_API_URL`, `KV_REST_API_TOKEN` | (대안) Upstash Redis |

저장소가 설정되지 않으면 서버 메모리에만 저장되므로 로컬 개발용으로만 쓸 수 있습니다.

## 실행 / 배포

```bash
npm run dev       # 로컬 개발
npm run preview   # Cloudflare Workers 환경으로 미리보기
npm run deploy    # Cloudflare Workers 배포
```
